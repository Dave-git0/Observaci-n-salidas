## Glosario

| Término | Definición con tus palabras |
|---|---|
| Salida | Resultado que muestra un sistema después de ejecutar una acción. |
| Resultado esperado | Resultado que debería mostrar el sistema correctamente. |
| Resultado obtenido | Resultado real que genera el sistema. |
| Validación | Proceso para comprobar si los datos y resultados son correctos. |
| Mensaje de error | Mensaje que informa que ocurrió un problema. |
| Mensaje de advertencia | Mensaje que alerta sobre un posible problema o dato sospechoso. |
| Mensaje de éxito | Mensaje que indica que una operación fue realizada correctamente. |
| Consola | Herramienta del navegador que muestra errores y mensajes técnicos. |
| Inspector | Herramienta para revisar y analizar elementos HTML y CSS. |
| Live Server | Extensión de VS Code que ejecuta proyectos web en tiempo real. |
| Terminal | Ventana para ejecutar comandos del sistema o programas. |
| NaN | Valor que significa que un dato no es un número válido. |
| undefined | Valor que aparece cuando una variable no tiene contenido definido. |
| Debug | Proceso de detectar y corregir errores en un programa. |
| Objetivo funcional | Función principal que debe cumplir un sistema. |
