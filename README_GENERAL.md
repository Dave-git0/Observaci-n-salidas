## Como usarlo

- Entrega a estudiantes solamente la carpeta `carpeta_estudiante/`.
- Conserva para ti la carpeta `carpeta_profesor/`.
- En clase, los estudiantes abren `carpeta_estudiante/` en VS Code y siguen el archivo `README.md`.
- El archivo del profesor contiene la guia detallada, las respuestas esperadas y los bloques exactos de codigo para perfeccionar el sistema.

## Producto esperado del estudiante

El estudiante entrega:

- Proyecto web corregido o perfeccionado.
- `evidencias/bitacora_practica_semana10.md` diligenciado.
- Registro de capturas.
- Conclusión breve sobre si el sistema cumple su objetivo.
